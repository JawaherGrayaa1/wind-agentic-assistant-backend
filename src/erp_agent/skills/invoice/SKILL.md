# Invoice (Facturation) Skill & Workflow Guide

## Overview

This skill handles the complete lifecycle of **Invoices (Factures)** in the ERP system:
1. **Creation**: Generates standard invoice documents with metadata (Client, Tax ID/MF, Date, Due Date, Payment Terms) and line items.
2. **Markdown Representation**: Stores and renders invoices as clean Markdown containing metadata headers, itemized calculation tables, and financial totals.
3. **Editing**: Allows adding, modifying, or removing items with instant mathematical re-calculation.
4. **Validation**: Enforces legal & accounting rules (client identification, positive amounts, valid tax rates, mathematical consistency) and transitions status from `draft` to `approved`.
5. **Export**: Compiles invoices to PDF format.

## Financial Formulas

1. **Line Brut HT:**
   $$\text{Brut HT} = \text{Quantity} \times \text{Unit Price}$$

2. **Line Remise / Discount:**
   $$\text{Remise Amount} = \text{Brut HT} \times \left(\frac{\text{Discount \%}}{100}\right)$$

3. **Line Net HT:**
   $$\text{Line Net HT} = \text{Brut HT} - \text{Remise Amount}$$

4. **Invoice Totals:**
   - **Total Brut HT** $= \sum \text{Line Brut HT}$
   - **Total Remises** $= \sum \text{Line Remise Amount} + \text{Global Remise}$
   - **Total Net HT** $= \text{Total Brut HT} - \text{Total Remises}$
   - **Total TVA (e.g. 19%)** $= \text{Total Net HT} \times \left(\frac{\text{Tax Rate \%}}{100}\right)$
   - **Timbre Fiscal** $= 1.000\text{ TND (if applicable)}$
   - **Total TTC** $= \text{Total Net HT} + \text{Total TVA} + \text{Timbre Fiscal}$

## Available Tools

- `create_invoice(client_name, client_tax_id, items, invoice_id, due_date, payment_terms, tax_rate, discount_pct, currency)`: Creates a new invoice document. (Requires confirmation).
- `get_invoice_summary(invoice_id)`: Computes and returns the itemized breakdown and compliance status. (Safe read action).
- `add_invoice_item(invoice_id, name, quantity, unit_price, discount_pct, product_id)`: Adds a line item to an invoice. (Requires confirmation).
- `update_invoice_item(invoice_id, line_number, product_id, name, quantity, unit_price, discount_pct)`: Modifies a line item. (Requires confirmation).
- `remove_invoice_item(invoice_id, line_number, product_id, name)`: Removes a line item. (Requires confirmation).
- `validate_invoice(invoice_id)`: Checks all legal/accounting criteria and updates status to `approved`. (Requires confirmation).
- `export_invoice_pdf(invoice_id, output_path)`: Exports invoice as a formatted PDF. (Requires confirmation).
